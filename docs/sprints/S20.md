## Architecture

### 1. Protocol Observers (Background Layer)

Watches for:
- **Confidence thresholds** (signal strength)
- **Misalignment signals** (odds movement vs prediction)
- **Tanking events** (line crashes)
- **Lineup volatility** (late scratches, injuries)

Filters through:
- User DNA constraints
- Risk profile
- Favorite sports
- Current exposure

Emits:
- `EligibleOpportunity` events
- `ConstraintViolation` (if opportunity exists but user can't take it)
- `SystemAlert` (global events)

### 2. Notification Rules Engine

Per-user configuration:
```json
{
  "notify_when_confidence_above": 0.75,
  "notify_only_for_favorite_sports": true,
  "max_notifications_per_day": 3,
  "avoid_high_volatility": true,
  "quiet_hours_start": "22:00",
  "quiet_hours_end": "08:00",
  "min_odds_threshold": 1.5,
  "max_odds_threshold": 10.0
}
```

### 3. Guardrails (Anti-Spam)

Global:
- System-wide cooldown between similar notifications (30 min)
- High entropy suppression (don't notify during chaos)
- Kill switch flag (emergency stop)

Per-user:
- Daily notification cap
- Sport-specific caps
- Duplicate suppression (same game, 24h)
