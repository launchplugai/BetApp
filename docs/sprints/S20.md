# Sprint S20: Notifications + Observers

**Branch:** `claude/s20-notifications`  
**Status:** 🟡 IN PROGRESS  
**Started:** 2026-02-13  
**Objective:** Real-time notifications for bet outcomes, signals, and system events

---

## Why S20

Users need to know:
- When their bets win/lose
- When edge signals appear
- When games they're tracking start/end
- Important system updates

Without notifications: users manually check app constantly.
With notifications: timely, contextual alerts drive engagement.

## Sprint Tickets

### S20-A: Notification Schema + Storage
**Status:** ⏳ PENDING  
**Scope:** Data model for notifications

**Deliverables:**
- [ ] `notifications` table
- [ ] `notification_preferences` table (per-user settings)
- [ ] `user_devices` table (for push tokens)

**Schema:**
```python
class NotificationType(str, Enum):
    BET_WON = "bet_won"
    BET_LOST = "bet_lost"
    BET_SETTLED = "bet_settled"
    SIGNAL_DETECTED = "signal_detected"
    GAME_STARTING = "game_starting"
    GAME_ENDED = "game_ended"
    SYSTEM_UPDATE = "system_update"
    PROMOTION = "promotion"

class Notification(BaseModel):
    id: str
    user_id: str
    type: NotificationType
    title: str
    body: str
    data: Dict[str, Any]  # Deep link payload
    read: bool = False
    sent_at: datetime
    read_at: Optional[datetime]

class NotificationPreferences(BaseModel):
    user_id: str
    bet_outcomes: bool = True
    signals: bool = True
    game_reminders: bool = True
    promotions: bool = False
    quiet_hours_start: Optional[time] = None  # 22:00
    quiet_hours_end: Optional[time] = None    # 08:00
```

**Files:**
- `app/models/notification.py`
- `app/models/notification_preferences.py`
- `migrations/003_create_notifications.py`

**Estimates:** 2 hours, 150 lines

### S20-C: Notification Triggers (Observers)
**Status:** ⏳ PENDING  
**Scope:** Hook into events to auto-send notifications

**Deliverables:**
- [ ] Bet settled observer → send win/lose notification
- [ ] Signal detected observer → send alert
- [ ] Game status observer → start/end reminders

**Events to watch:**
```python
# Bet settlement
on_bet_settled(bet_id, result) -> notify_user()

# Signal detection
on_signal_detected(signal) -> notify_subscribed_users()

# Game lifecycle
on_game_starting(game_id, minutes_until) -> notify_tracking_users()
on_game_ended(game_id) -> settle_pending_bets()
```

**Files:**
